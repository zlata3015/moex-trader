# moex-trader — трейдинг на Московской бирже для Claude

16 скиллов: технический анализ, сканер, таймер входа, план выхода, машина времени, бэктест с комиссиями,
размер позиции, риск-менеджер, Т-Инвестиции, оповещения, журнал, новости, аналитика компаний и макрофон.
Акции, фонды, облигации, валюта и фьючерсы FORTS. Чистый Python 3.8+, ничего устанавливать не нужно.

Основано на идее и структуре [day-trader-skill](https://github.com/Jakeschincariol/day-trader-skill) (MIT),
переписано под Мосбиржу: данные ISS, лоты, шаг цены и ГО, сессии МСК, дивидендные отсечки, Т-Инвестиции.

## Одна сделка

```
moex-macro → moex-scanner → moex-ta → moex-news → moex-entry → moex-exit
→ moex-timemachine → moex-budget → moex-risk → moex-broker → moex-alerts → moex-journal
```
До реальных денег — `moex-backtest`: стратегия должна быть в плюсе на отложенном периоде после комиссий.

| скилл | что делает |
| --- | --- |
| moex-trend | тренд сверху вниз: месяц/неделя/день, вход по сигналу в тренде, подтягиваемый стоп |
| moex-setup | настройки (счёт, риск, тариф), проверка подключения, токен Т-Инвестиций |
| moex-ta | 15+ индикаторов, уровни, паттерны, дивергенции, мульти-таймфрейм, оценка ±100, график |
| moex-scanner | ликвидные бумаги, пробои диапазона открытия, свинг- и внутридневные сетапы, рейтинг ТА |
| moex-news | Интерфакс, РБК, Коммерсантъ, Smart-Lab, ТАСС, новости биржи, теги, дивиденды |
| moex-entry | следит за сетапом по закрытым барам: ждём / сработал / истёк, с подтверждением ТА |
| moex-exit | стоп (диапазон, ATR, свинг), цель (R, сопротивление), закрытие по времени |
| moex-timemachine | 10 000 сценариев по барам самой бумаги + то же правило на прошлых днях |
| moex-backtest | бэктест с комиссией и проскальзыванием, оптимизация 70/30, рейтинг бумаг |
| moex-budget | лоты под риск: акции, фонды, облигации (номинал, НКД), фьючерсы (шаг, ГО) |
| moex-risk | 20+ проверок: лимиты, сессия, аукцион, клиринг, лимиты цены, экспирация, отсечка, бэктест |
| moex-broker | Т-Инвестиции: песочница по умолчанию, только после PASS и вашего «да»; стоп и тейк |
| moex-alerts | цена, стоп/цель (одно отменяет другое), время, RSI |
| moex-journal | дневник сделок, статистика по сетапам/бумагам/дням/часам, что выключить |
| moex-analyst | капитализация, динамика, дивиденды и доходность, индексы, отчётность МСФО |
| moex-macro | ключевая ставка, курсы ЦБ, IMOEX, RGBI, Si, Brent, режим рынка |

## Данные и сеть

- **ISS Мосбиржи** (iss.moex.com) — бесплатно и без ключа, но рыночные данные с задержкой около 15 минут.
- **Т-Инвестиции** (T-Invest API) — свечи и цены в реальном времени и заявки. Нужен токен из приложения
  (Настройки → Токены T-Invest API). Токен хранится в переменной `TINVEST_TOKEN` или в файле
  `~/.config/moex-trader/tinvest_token` и **никогда не вставляется в чат**.
- Скрипты ходят в интернет напрямую. В облачной среде Claude с ограниченной сетью запускайте их на своём
  компьютере (подключите компьютер к чату) или передавайте свечи файлом: `--file export.csv` (CSV Финама/терминала).

## Безопасность

- `"paper": true` по умолчанию — песочница Т-Инвестиций, учебные деньги.
- Заявка уходит только после PASS от moex-risk на сегодня, вашего дословного «да» на этот тикет и
  подтверждения запуска команды. Повторно та же заявка не отправляется.
- Нет плеча, шортов, фьючерсов и вечерней сессии, пока вы сами не включите их в `trader/config.json`.

## Тесты

```bash
python3 tests/make_fixtures.py          # синтетические данные в формате ответов ISS
python3 -m unittest discover -s tests -v
```
Тесты работают без сети на фикстурах в формате ISS и на имитации ответов T-Invest API. На живых данных
биржи пакет пока не прогонялся — первый запуск проверьте командой `moex-setup check`.

## Важно

**Это не финансовая рекомендация.** Программа читает публичные данные и считает. Она не знает вашей ситуации
и не видит будущего. Большинство людей, торгующих внутри дня, теряют деньги, и комиссии — одна из главных
причин. Прошлые результаты, бэктест и симуляции не гарантируют будущих. Стоп — это план, а не гарантия:
на гэпе он исполнится хуже. Налоги: НДФЛ 13–15% с прибыли, брокер удерживает сам; ИИС меняет правила.
Начинайте с песочницы, минимум месяц, и переходите на реальные деньги только если журнал в плюсе.
