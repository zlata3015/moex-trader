# moex-broker — Т-Инвестиции

Единственный скилл пакета, который может привести к реальной заявке, поэтому самый строгий. Заявка уходит, только когда выполнены **все** условия:
1. moex-risk дал **PASS** этой заявке сегодня (сверка по отпечатку);
2. пользователь в чате написал **«да»** именно на этот тикет (записывается дословно);
3. запуск `place` подтверждён в окне разрешения на выполнение команды.

```bash
python3 "${CLAUDE_SKILL_DIR}/broker.py" show                           # тикеты простыми словами
python3 "${CLAUDE_SKILL_DIR}/broker.py" approve --index 1 --reply "да"  # ДОСЛОВНЫЙ ответ пользователя
python3 "${CLAUDE_SKILL_DIR}/broker.py" place --index 1
python3 "${CLAUDE_SKILL_DIR}/broker.py" status --index 1                # исполнение -> портфель
python3 "${CLAUDE_SKILL_DIR}/broker.py" protect --index 1               # стоп-лосс + тейк-профит
python3 "${CLAUDE_SKILL_DIR}/broker.py" cancel --index 1
python3 "${CLAUDE_SKILL_DIR}/broker.py" flatten --symbol SBER           # заявка на закрытие (тоже через «да»)
python3 "${CLAUDE_SKILL_DIR}/broker.py" fill --symbol SBER --side buy --lots 6 --price 440.95   # ручная запись
python3 "${CLAUDE_SKILL_DIR}/broker.py" accounts | sandbox-open --amount 100000 | portfolio | log
```

## Порядок

1. `show` → перескажите тикет: что, сколько, по какой цене, стоп, цель, убыток на стопе, **песочница или реальный счёт**.
2. Спросите: «Отправить эту заявку? Ответьте да или нет». Ждите ответа. Сами «да» не додумывайте, ответ на другой вопрос подтверждением не считается.
3. `approve` с дословным ответом. Если скрипт не принял ответ, заявка не одобрена.
4. `place`. Затем `status`; после исполнения сразу `protect`. Если песочница не приняла стоп-заявки, поставьте moex-alerts `add --from-plan`.
5. Для внутридневной позиции к `flat_by`: `flatten` → `show` → «да» → `approve` → `place`, затем снимите стоп-заявки в приложении.

## Настройка Т-Инвестиций

- Токен — только из переменной `TINVEST_TOKEN` (`TINVEST_SANDBOX_TOKEN` для песочницы) или из файла `~/.config/moex-trader/tinvest_token`. **Никогда не просите токен в чате и не выводите его.** Если токен оказался в переписке, попросите пользователя отозвать его в приложении.
- Песочница: `sandbox-open --amount 100000` → пропишите id в `tinvest_account_id`.
- Реальный счёт (`paper: false`) — только по явной просьбе пользователя. Напомните, что это реальные деньги, и предложите сначала проверить журнал песочницы.
- Другой брокер (БКС, Финам, Альфа): заявку пользователь вводит в терминале сам по тикету из `show`, а исполнение записывается через `fill`, чтобы работали лимиты и журнал.
- Без плеча, маржи и шортов, пока пользователь сам не включит их в конфиге.

## Общие правила

- Скрипты лежат в `${CLAUDE_SKILL_DIR}`, общая библиотека — в `${CLAUDE_SKILL_DIR}/../moex-setup/lib`. Состояние пишется в папку `trader/` текущего проекта (или `$TRADER_DIR`).
- Время везде — московское (МСК). `--now "YYYY-MM-DD HH:MM"` разбирает ситуацию на момент в прошлом.
- Бесплатные данные ISS Мосбиржи идут с задержкой около 15 минут. В реальном времени — через токен Т-Инвестиций (настраивается в moex-setup).
- Если скрипт пишет, что нет доступа к iss.moex.com или API Т-Инвестиций, значит у среды нет выхода в интернет к этим сайтам. Если подключён компьютер пользователя (есть инструмент для команд на его компьютере), запустите команду там. Иначе предложите выгрузить свечи в CSV (терминал брокера, экспорт Финама) и передать файл через `--file`. Не придумывайте цифры.
- Это инструмент, а не финансовая рекомендация. Не обещайте прибыль. Большинство людей, торгующих внутри дня, теряют деньги; комиссии — одна из главных причин.
