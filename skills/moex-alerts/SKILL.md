# moex-alerts — оповещения

```bash
python3 "${CLAUDE_SKILL_DIR}/alerts.py" add --from-plan                  # стоп, цель, «закрыть до»
python3 "${CLAUDE_SKILL_DIR}/alerts.py" add --symbol SBER --above 330 --note "пробой"
python3 "${CLAUDE_SKILL_DIR}/alerts.py" add --symbol SBER --rsi-below 30 --tf 15m
python3 "${CLAUDE_SKILL_DIR}/alerts.py" add --at 18:30 --note "закрыть внутридневное"
python3 "${CLAUDE_SKILL_DIR}/alerts.py" check                            # 🔔 то, что сработало
python3 "${CLAUDE_SKILL_DIR}/alerts.py" watch --every 60
python3 "${CLAUDE_SKILL_DIR}/alerts.py" list | clear [--fired]
```

## Как работать

- Оповещения проверяются, только когда запущен `check`. Для фона предложите запланированную задачу, которая каждые 5–15 минут в торговые часы запускает `check` и присылает уведомление при 🔔.
- Без токена Т-Инвестиций цена берётся из ISS с задержкой около 15 минут — для стопа это много. Скажите об этом и предложите выставить настоящую стоп-заявку у брокера (moex-broker `protect`).
- Сработал стоп или цель — предложите закрыть позицию через moex-broker и записать результат.

## Общие правила

- Скрипты лежат в `${CLAUDE_SKILL_DIR}`, общая библиотека — в `${CLAUDE_SKILL_DIR}/../moex-setup/lib`. Состояние пишется в папку `trader/` текущего проекта (или `$TRADER_DIR`).
- Время везде — московское (МСК). `--now "YYYY-MM-DD HH:MM"` разбирает ситуацию на момент в прошлом.
- Бесплатные данные ISS Мосбиржи идут с задержкой около 15 минут. В реальном времени — через токен Т-Инвестиций (настраивается в moex-setup).
- Если скрипт пишет, что нет доступа к iss.moex.com или API Т-Инвестиций, значит у среды нет выхода в интернет к этим сайтам. Если подключён компьютер пользователя (есть инструмент для команд на его компьютере), запустите команду там. Иначе предложите выгрузить свечи в CSV (терминал брокера, экспорт Финама) и передать файл через `--file`. Не придумывайте цифры.
- Это инструмент, а не финансовая рекомендация. Не обещайте прибыль. Большинство людей, торгующих внутри дня, теряют деньги; комиссии — одна из главных причин.
