# moex-timemachine — машина времени

```bash
python3 "${CLAUDE_SKILL_DIR}/timemachine.py" run --write                 # 10 000 сессий, seed 19
python3 "${CLAUDE_SKILL_DIR}/timemachine.py" run --sims 20000 --seed 7 --sessions 59
```
Читает `trader/plan.json`, пишет `trader/state/timemachine.json`. Один и тот же seed даёт тот же результат — его можно повторить.

## Как читать

- **Цель раньше стопа / стоп раньше цели / по времени** — доли из 10 000 сценариев. Если в одном баре задеты и стоп, и цель, считается стоп (консервативно).
- **В среднем на сделку после издержек** — главное число. Около нуля — это монетка; отрицательное — сделка в среднем теряет после комиссий.
- **История** — то же правило на реальных прошлых сессиях. Если сделок 30 и больше, история весит больше случайной модели.
- **Вывод** — передайте его дословно и без смягчений. «Близко к монетке» — значит преимущества нет, и пропустить сделку — нормальное решение.
- Модель строится на 60 днях баров. Отчётность, решение ЦБ, санкции, торговая пауза могут сделать то, чего в этих днях не было. Это проверка реальностью, а не прогноз.

## Общие правила

- Скрипты лежат в `${CLAUDE_SKILL_DIR}`, общая библиотека — в `${CLAUDE_SKILL_DIR}/../moex-setup/lib`. Состояние пишется в папку `trader/` текущего проекта (или `$TRADER_DIR`).
- Время везде — московское (МСК). `--now "YYYY-MM-DD HH:MM"` разбирает ситуацию на момент в прошлом.
- Бесплатные данные ISS Мосбиржи идут с задержкой около 15 минут. В реальном времени — через токен Т-Инвестиций (настраивается в moex-setup).
- Если скрипт пишет, что нет доступа к iss.moex.com или API Т-Инвестиций, значит у среды нет выхода в интернет к этим сайтам. Если подключён компьютер пользователя (есть инструмент для команд на его компьютере), запустите команду там. Иначе предложите выгрузить свечи в CSV (терминал брокера, экспорт Финама) и передать файл через `--file`. Не придумывайте цифры.
- Это инструмент, а не финансовая рекомендация. Не обещайте прибыль. Большинство людей, торгующих внутри дня, теряют деньги; комиссии — одна из главных причин.
