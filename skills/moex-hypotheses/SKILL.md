# moex-hypotheses — реестр гипотез

```bash
python3 "${CLAUDE_SKILL_DIR}/hypotheses.py" list                     # всё, включая опровергнутое
python3 "${CLAUDE_SKILL_DIR}/hypotheses.py" list --status candidate
python3 "${CLAUDE_SKILL_DIR}/hypotheses.py" show B10
python3 "${CLAUDE_SKILL_DIR}/hypotheses.py" add E01 --claim "..." --family equities-macro --rule "..."
python3 "${CLAUDE_SKILL_DIR}/hypotheses.py" check E01 --asset asset.csv --signal signal.csv --key key.csv --since 2015-01-01
python3 "${CLAUDE_SKILL_DIR}/hypotheses.py" signals                  # только допущенные к рекомендациям
python3 "${CLAUDE_SKILL_DIR}/hypotheses.py" run-bonds                # воспроизвести проверку облигаций, нужен доступ к ISS и cbr.ru
```

CSV: `дата,значение`. Сигнал: 1 в рынке, 0 в деньгах, на дату решения. Покупка закрытием следующего торгового дня.
Сигнал на дату нельзя строить из данных, опубликованных позже этой даты.

## Порядок

1. Записать гипотезу и правило через `add` до расчёта. Гипотезы, записанные после просмотра данных, получают `prereg: false`.
2. Правило после записи не меняется. Новый порог — новая гипотеза того же семейства.
3. Проверить через `check`. Статус ставит только скрипт. Вручную через `reject` можно лишь перенести отказ из другой проверки со ссылкой на документ.
4. Отвергнутое не удалять. Размер семейства ужесточает порог для следующих гипотез.

## Статусы

| Статус | Значение | В рекомендации |
|---|---|---|
| planned | записана, не проверена | нет |
| rejected | не прошла порог | нет |
| risk_filter | не теряет премии и вдвое режет просадку, но не сигнал покупки | только как ограничение риска |
| candidate | премия выше нуля, p ≤ 0,20, плюс минимум в 2 периодах, выдерживает задержку на месяц и двойные издержки | нет |
| confirmed | плюс во всех периодах, p ≤ 0,05 ÷ размер семейства, объём выборки, задержка и издержки | да, после песочницы (этап 4) |
| sandbox, live | этапы 4 и 5, перевод через `promote` | да |

Объём выборки: частые сигналы (`frequent`) — 100+ сделок. Редкие (`rare`, циклы ставки и другие макрособытия) — 5+ заходов и минимум 2/3 лучше денег: 100 сделок там физически недостижимы.

Деньги считаются как ключевая ставка минус 1%. Сравнение с другим активом — `--base` или `H.evaluate(money=...)`. Событийный разбор — `H.evaluate_events`: избыток после издержек на событие, перекрывающиеся события пропускаются. Отраслевые индексы Мосбиржи ценовые: без дивидендов.

## Как отвечать

Разделяйте факт, расчёт и мнение. Называйте статус, число проверенных гипотез семейства и что не проверено. Если `signals` пуст, рыночные закономерности из реестра не являются основанием для сделки.
