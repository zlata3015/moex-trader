# moex-backtest — проверка на истории

```bash
python3 "${CLAUDE_SKILL_DIR}/backtest.py" orb SBER --days 120 --trades
python3 "${CLAUDE_SKILL_DIR}/backtest.py" orb SBER --trend --regime --volume 1.5 --target 2
python3 "${CLAUDE_SKILL_DIR}/backtest.py" swing GAZP --setup pullback --stop-atr 2 --target 2 --hold 10
python3 "${CLAUDE_SKILL_DIR}/backtest.py" optimize SBER --strategy orb
python3 "${CLAUDE_SKILL_DIR}/backtest.py" universe --strategy orb --limit 20
python3 "${CLAUDE_SKILL_DIR}/backtest.py" universe --strategy swing --limit 30
# тренд сверху вниз + подтягиваемый стоп (дневки, позиция на дни-недели):
python3 "${CLAUDE_SKILL_DIR}/backtest.py" trend SBER --trades
python3 "${CLAUDE_SKILL_DIR}/backtest.py" trend SBER --short --trail-atr 3 --stop-atr 2
python3 "${CLAUDE_SKILL_DIR}/backtest.py" trend-optimize SBER
python3 "${CLAUDE_SKILL_DIR}/backtest.py" trend-universe --short
python3 "${CLAUDE_SKILL_DIR}/backtest.py" trend-universe --files-dir ~/moex   # по выгрузкам SYM_D.csv / SYM_M.csv / IMOEX_D.csv
python3 "${CLAUDE_SKILL_DIR}/backtest.py" trend-universe --since 2019-01-01 --by-year --regime
python3 "${CLAUDE_SKILL_DIR}/backtest.py" trend-portfolio --since 2019-01-01 --regime --capital 100000 --risk 1
#   один счёт по всем бумагам, лимиты позиций, свободные деньги в фонде денежного рынка; сравнение с фондом и индексом
```
Для стратегии тренда сначала смотрите \`trend-universe\` с одними параметрами для всех бумаг — это честнее оптимизации. Сделка, открытая на конец данных, помечена «открыта» и посчитана по последней цене.
Издержки берутся из конфига: `fee_pct` за сторону (или `futures_fee_rub` за контракт) плюс `slippage_ticks` шагов цены. Итоги пишутся в `trader/backtest/summary.json` — их читают moex-risk и moex-scanner.

## Как отвечать на вопрос «какая стратегия будет в плюсе»

1. Честно: заранее этого не знает никто. Ответ даёт только проверка на истории этой бумаги с реальными издержками, а затем песочница.
2. Запустите `universe` для обоих типов стратегий и покажите, где результат на **проверке** (отложенный период) в плюсе и сделок достаточно (от 20–30).
3. Объясните цифры: среднее +0,2R при риске 1000 ₽ — это около +200 ₽ на сделку в среднем, с неизбежными сериями убытков (покажите максимальную просадку).
4. Предупредите о подгонке: `optimize` перебирает около 100 комбинаций, поэтому результат на обучении завышен. Доверять можно только проверке и только при t-статистике около 2 и выше.
5. Покажите, сколько съедают издержки. Если на 5-минутных барах они больше 0,2R за сделку, предложите шире стоп и дальше цель (меньше сделок, выше качество), свинг вместо торговли внутри дня или тариф с меньшей комиссией.
6. Предложите `require_backtest: true` — тогда moex-risk блокирует сетапы, которые на истории теряют.
7. Главный итог показывайте через \`trend-portfolio\`: рубли на счёте, годовые, худшая просадка — и сравнение с фондом денежного рынка. Стратегия имеет смысл, только если обгоняет фонд.
8. Цены ISS уже скорректированы на дробления; дивиденды учитываются (лонг через отсечку получает, шорт платит). Если ISS не отдаёт дивиденды, они берутся со smart-lab.ru.
9. Прошлый результат не гарантирует будущий. После бэктеста — минимум месяц в песочнице и сверка с moex-journal.

## Общие правила

- Скрипты лежат в `${CLAUDE_SKILL_DIR}`, общая библиотека — в `${CLAUDE_SKILL_DIR}/../moex-setup/lib`. Состояние пишется в папку `trader/` текущего проекта (или `$TRADER_DIR`).
- Время везде — московское (МСК). `--now "YYYY-MM-DD HH:MM"` разбирает ситуацию на момент в прошлом.
- Бесплатные данные ISS Мосбиржи идут с задержкой около 15 минут. В реальном времени — через токен Т-Инвестиций (настраивается в moex-setup).
- Если скрипт пишет, что нет доступа к iss.moex.com или API Т-Инвестиций, значит у среды нет выхода в интернет к этим сайтам. Если подключён компьютер пользователя (есть инструмент для команд на его компьютере), запустите команду там. Иначе предложите выгрузить свечи в CSV (терминал брокера, экспорт Финама) и передать файл через `--file`. Не придумывайте цифры.
- Это инструмент, а не финансовая рекомендация. Не обещайте прибыль. Большинство людей, торгующих внутри дня, теряют деньги; комиссии — одна из главных причин.
