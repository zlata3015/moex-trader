# moex-scanner — сканер

```bash
python3 "${CLAUDE_SKILL_DIR}/scan.py" universe --kind shares          # ликвидные бумаги, оборот, изменение
python3 "${CLAUDE_SKILL_DIR}/scan.py" orb --at 09:30 --range 15       # пробой диапазона 09:00–09:15
python3 "${CLAUDE_SKILL_DIR}/scan.py" orb --kind futures              # то же на фьючерсах
python3 "${CLAUDE_SKILL_DIR}/scan.py" intraday --tf 15m               # внутридневные сетапы
python3 "${CLAUDE_SKILL_DIR}/scan.py" swing                           # дневные свинг-сетапы
python3 "${CLAUDE_SKILL_DIR}/scan.py" ta --tf 1h --top 10             # рейтинг по оценке ТА (сильные и слабые)
python3 "${CLAUDE_SKILL_DIR}/scan.py" find сбер                       # найти тикер
```
`--kind`: shares, futures, currency, etf, bonds (ОФЗ), corp (корпоративные), all. `--min-turnover` — минимальный оборот за день в ₽ (по умолчанию из конфига, 100 млн). `--limit` — сколько самых ликвидных проверять. Результат — `trader/scan.json`.

## Как работать

- Перед сканом загляните в moex-macro: в медвежьем режиме IMOEX лонги сканировать можно, но размер — меньше.
- Диапазон открытия по умолчанию от начала основной сессии (`orb_start`, 09:00). Сканировать не раньше, чем диапазон сформирован (09:15 при --range 15).
- Если есть `trader/backtest/summary.json`, в первую очередь предлагайте бумаги и сетапы, которые в плюсе на проверке (OOS). Бумагу, где стратегия на истории теряет, назовите прямо.
- Выведите 3–7 лучших кандидатов с причиной и предложите разобрать одного через moex-ta, а затем moex-entry.
- Скан — это список кандидатов, а не сигналы к покупке.

## Общие правила

- Скрипты лежат в `${CLAUDE_SKILL_DIR}`, общая библиотека — в `${CLAUDE_SKILL_DIR}/../moex-setup/lib`. Состояние пишется в папку `trader/` текущего проекта (или `$TRADER_DIR`).
- Время везде — московское (МСК). `--now "YYYY-MM-DD HH:MM"` разбирает ситуацию на момент в прошлом.
- Бесплатные данные ISS Мосбиржи идут с задержкой около 15 минут. В реальном времени — через токен Т-Инвестиций (настраивается в moex-setup).
- Если скрипт пишет, что нет доступа к iss.moex.com или API Т-Инвестиций, значит у среды нет выхода в интернет к этим сайтам. Если подключён компьютер пользователя (есть инструмент для команд на его компьютере), запустите команду там. Иначе предложите выгрузить свечи в CSV (терминал брокера, экспорт Финама) и передать файл через `--file`. Не придумывайте цифры.
- Это инструмент, а не финансовая рекомендация. Не обещайте прибыль. Большинство людей, торгующих внутри дня, теряют деньги; комиссии — одна из главных причин.
