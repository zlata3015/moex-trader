# moex-portfolio — обзор портфеля

```bash
python3 "${CLAUDE_SKILL_DIR}/review.py"
python3 "${CLAUDE_SKILL_DIR}/review.py" --offline
```

Читает `trader/portfolio.json` и `trader/state/broker.json`. Перед разбором реального счёта выполните `moex-broker reconcile`.

Стресс-сценарии считаются без стопов: при гэпе или закрытии торгов стоп не защищает. Просадка из сценария сравнивается с лимитом Маргариты. Если сценарий выходит за лимит, скажите об этом прямо.
