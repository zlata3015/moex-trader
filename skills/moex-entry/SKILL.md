# moex-entry — таймер входа

```bash
python3 "${CLAUDE_SKILL_DIR}/entry.py" check SBER --setup orb                  # ждём / сработал / истёк
python3 "${CLAUDE_SKILL_DIR}/entry.py" check SBER --setup breakout --level 330 --tf 15m
python3 "${CLAUDE_SKILL_DIR}/entry.py" check GAZP --setup pullback --tf 1h
python3 "${CLAUDE_SKILL_DIR}/entry.py" watch SBER --setup orb --every 30 --max-minutes 90
```
Сетапы: orb, breakout, pullback, rsi-bounce, squeeze, vwap-reclaim. Используются только **закрытые** бары. Результат — `trader/entry.json`; moex-exit берёт оттуда цену входа и диапазон.

## Статусы

- **ждём** — условие ещё не выполнено. Для breakout показано, сколько процентов до уровня.
- **сработал** — бар закрылся за уровнем; цена входа — закрытие этого бара.
- **истёк** — позже `no_entry_after` или для пробоя вверх цена ушла под диапазон. Сделку пропускаем, без исключений.
- **диапазон формируется** — ещё рано.

## Как работать

- Если сработал, но технический анализ против (оценка ≤ −15), прямо скажите, что сигнал слабый.
- Объём ×1,5 и выше к среднему на пробое — лучше; пробой на низком объёме чаще оказывается ложным.
- `watch` подходит, пока пользователь ждёт в чате. Для фонового наблюдения предложите запланированную задачу, которая запускает `check` каждые несколько минут, или moex-alerts.
- После «сработал» — сразу moex-exit, затем moex-timemachine, а не покупка.

## Общие правила

- Скрипты лежат в `${CLAUDE_SKILL_DIR}`, общая библиотека — в `${CLAUDE_SKILL_DIR}/../moex-setup/lib`. Состояние пишется в папку `trader/` текущего проекта (или `$TRADER_DIR`).
- Время везде — московское (МСК). `--now "YYYY-MM-DD HH:MM"` разбирает ситуацию на момент в прошлом.
- Бесплатные данные ISS Мосбиржи идут с задержкой около 15 минут. В реальном времени — через токен Т-Инвестиций (настраивается в moex-setup).
- Если скрипт пишет, что нет доступа к iss.moex.com или API Т-Инвестиций, значит у среды нет выхода в интернет к этим сайтам. Если подключён компьютер пользователя (есть инструмент для команд на его компьютере), запустите команду там. Иначе предложите выгрузить свечи в CSV (терминал брокера, экспорт Финама) и передать файл через `--file`. Не придумывайте цифры.
- Это инструмент, а не финансовая рекомендация. Не обещайте прибыль. Большинство людей, торгующих внутри дня, теряют деньги; комиссии — одна из главных причин.
