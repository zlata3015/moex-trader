# moex-setup — настройка и карта пакета

```bash
python3 "${CLAUDE_SKILL_DIR}/setup.py" init --account 100000   # создать trader/config.json
python3 "${CLAUDE_SKILL_DIR}/setup.py" check                   # доступ к ISS и Т-Инвестициям
python3 "${CLAUDE_SKILL_DIR}/setup.py" config                  # действующие настройки
python3 "${CLAUDE_SKILL_DIR}/setup.py" set max_loss_per_trade '"1%"'
```

## Первый запуск

1. Спросите размер счёта, сколько пользователь готов потерять в одной сделке (обычно 0,5–1% счёта) и за день (2–3%), и тариф брокера (на «Трейдере» Т-Инвестиций около 0,05% за сторону, на «Инвесторе» около 0,3%; комиссия напрямую решает, будет ли стратегия в плюсе). Запустите `init`, затем `set` нужные значения.
2. `check` — проверка доступа.
3. Токен Т-Инвестиций нужен только для данных в реальном времени и отправки заявок. **Никогда не просите вставить токен в чат.** Объясните: приложение Т-Инвестиций → Настройки → Токены T-Invest API → создать токен (для начала — для песочницы или «только чтение»). Затем пользователь сам сохраняет его в переменную окружения `TINVEST_TOKEN` или в файл `~/.config/moex-trader/tinvest_token` (права 600). Скрипты токен никогда не печатают.
4. По умолчанию `"paper": true` — песочница. Переводить на реальный счёт только по явной просьбе пользователя, после месяца в песочнице и положительного журнала. Предупредите, что это реальные деньги.

## Ключевые настройки config.json

| ключ | что значит |
| --- | --- |
| account_size, max_loss_per_trade, daily_loss_limit, weekly_loss_limit | капитал, риск на сделку ("0.5%"), дневной и недельный стоп |
| max_open_risk, dd_half_pct, dd_stop_pct | суммарный открытый риск, просадка до урезания объёма и до паузы |
| corr_threshold, corr_group_risk_mult, issuer_limit_pct | связанные позиции считаются одной; лимит на эмитента облигаций |
| max_trades_per_day, max_open_positions, max_position_pct | лимиты активности и концентрации |
| min_reward_risk, min_target_cost_multiple | минимум прибыль/риск и «до цели не меньше N издержек» |
| fee_pct, futures_fee_pct, slippage_ticks | комиссия за сторону, % от стоимости контракта, проскальзывание в шагах цены |
| max_data_age_days, reconcile_ignore | возраст свечей, после которого новая сделка блокируется; тикеры брокера вне учёта |
| tax_pct, fund_spread_pct | НДФЛ и разница фонда с ключевой ставкой для расчёта облигаций |
| require_trend_alignment, trail_atr, max_hold_days_position | сделки только по тренду М/Н/Д, подтягиваемый стоп в ATR, срок позиции |
| regime_filter, require_backtest | фильтр режима рынка (IMOEX), запрет сетапов без плюса на истории |
| allow_short, allow_futures, allow_bonds, allow_currency, allow_evening_session | что разрешено |
| sessions, orb_start, flat_by, no_entry_after | расписание МСК (с 14.09.2026 основная сессия 09:00–19:00), начало диапазона открытия, время закрытия |

## Карта пакета

Основной способ (по тренду, на дни-недели): `moex-trend scan` → `moex-trend analyze --plan` → `moex-budget` → `moex-risk` → `moex-broker` → каждый вечер `moex-exit update`.
Внутри дня: `moex-macro` (фон) → `moex-scanner` → `moex-ta` → `moex-news` → `moex-entry` → `moex-exit` → `moex-timemachine` → `moex-budget` → `moex-risk` → `moex-broker` → `moex-alerts` → `moex-journal`.
До реальных денег: `moex-backtest` — проверить, что выбранная стратегия в плюсе после издержек.
Фундамент: `moex-analyst`. Облигации: `moex-bonds`. Весь портфель: `moex-portfolio`.

## Общие правила

- Скрипты лежат в `${CLAUDE_SKILL_DIR}`, общая библиотека — в `${CLAUDE_SKILL_DIR}/../moex-setup/lib`. Состояние пишется в папку `trader/` текущего проекта (или `$TRADER_DIR`).
- Время везде — московское (МСК). `--now "YYYY-MM-DD HH:MM"` разбирает ситуацию на момент в прошлом.
- Бесплатные данные ISS Мосбиржи идут с задержкой около 15 минут. В реальном времени — через токен Т-Инвестиций (настраивается в moex-setup).
- Если скрипт пишет, что нет доступа к iss.moex.com или API Т-Инвестиций, значит у среды нет выхода в интернет к этим сайтам. Если подключён компьютер пользователя (есть инструмент для команд на его компьютере), запустите команду там. Иначе предложите выгрузить свечи в CSV (терминал брокера, экспорт Финама) и передать файл через `--file`. Не придумывайте цифры.
- Это инструмент, а не финансовая рекомендация. Не обещайте прибыль. Большинство людей, торгующих внутри дня, теряют деньги; комиссии — одна из главных причин.
