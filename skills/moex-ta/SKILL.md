# moex-ta — технический анализ

```bash
python3 "${CLAUDE_SKILL_DIR}/ta_report.py" mtf SBER --mode intraday   # день → час → 15м → 5м
python3 "${CLAUDE_SKILL_DIR}/ta_report.py" mtf SBER --mode swing      # неделя → день → 4ч → час
python3 "${CLAUDE_SKILL_DIR}/ta_report.py" analyze SiZ6 --tf 15m      # один таймфрейм, все индикаторы
python3 "${CLAUDE_SKILL_DIR}/ta_report.py" levels GAZP --tf 1d        # уровни, пивоты, Фибоначчи
python3 "${CLAUDE_SKILL_DIR}/ta_report.py" chart SBER --tf 1h --plan  # график -> trader/charts/SBER-1h.html
```
Таймфреймы: 1m 5m 10m 15m 30m 1h 4h 1d 1w 1M. Фьючерс можно назвать кодом актива (`Si`, `BR`, `RI`) — берётся ближайший контракт. `--json` — машиночитаемо. Результат сохраняется в `trader/ta/<тикер>.json`.

## Как считается оценка

Каждый сигнал имеет вес. Тренд по средним (±20), пересечение EMA20/50 (±10), ADX>25 по направлению DI (±8), RSI (перепроданность +10 / перекупленность −10, сила ±5), MACD (пересечение ±12, положение ±5), Боллинджер (±4, сжатие — нейтрально, «ждите выхода»), стохастик из зон (±8), Supertrend (±6, смена +8), VWAP дня (±6), всплеск объёма (±6), OBV (±3), близость поддержки/сопротивления (±5), пробой максимума/минимума 20 баров (±10), свечные паттерны (±6), дивергенция RSI (±10). Сумма ограничена ±100: ≥40 сильный бычий, ≥15 бычий, −15…15 нейтральный и так далее.

Мульти-таймфрейм взвешивает: для торговли внутри дня день 30%, час 25%, 15 мин 25%, 5 мин 20%; для свинга неделя 30%, день 35%, 4 ч 20%, час 15%. «Все таймфреймы смотрят в одну сторону» — самый качественный случай.

## Как отвечать пользователю

1. Сначала `mtf` в режиме под его стиль. Если стиль неизвестен — спросите: внутри дня или свинг.
2. Изложите по-человечески: старший тренд, где мы внутри него (у поддержки, в середине, у сопротивления), что говорит таймфрейм входа, есть ли противоречия. Цифры — только из вывода скрипта.
3. Сделку предлагайте только по направлению старшего тренда. Когда таймфреймы спорят или оценка нейтральная, лучший совет — «ждать».
4. Для уровней стопа и цели передайте работу moex-exit (стоп по ATR или за свингом, цель у ближайшего сопротивления).
5. График: `chart`, затем отправьте HTML-файл пользователю.
6. Технический анализ описывает вероятности, а не гарантирует их. Перед реальными деньгами — moex-backtest.

## Общие правила

- Скрипты лежат в `${CLAUDE_SKILL_DIR}`, общая библиотека — в `${CLAUDE_SKILL_DIR}/../moex-setup/lib`. Состояние пишется в папку `trader/` текущего проекта (или `$TRADER_DIR`).
- Время везде — московское (МСК). `--now "YYYY-MM-DD HH:MM"` разбирает ситуацию на момент в прошлом.
- Бесплатные данные ISS Мосбиржи идут с задержкой около 15 минут. В реальном времени — через токен Т-Инвестиций (настраивается в moex-setup).
- Если скрипт пишет, что нет доступа к iss.moex.com или API Т-Инвестиций, значит у среды нет выхода в интернет к этим сайтам. Если подключён компьютер пользователя (есть инструмент для команд на его компьютере), запустите команду там. Иначе предложите выгрузить свечи в CSV (терминал брокера, экспорт Финама) и передать файл через `--file`. Не придумывайте цифры.
- Это инструмент, а не финансовая рекомендация. Не обещайте прибыль. Большинство людей, торгующих внутри дня, теряют деньги; комиссии — одна из главных причин.
