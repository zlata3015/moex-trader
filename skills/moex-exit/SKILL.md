# moex-exit — план выхода

```bash
python3 "${CLAUDE_SKILL_DIR}/exit.py" plan --stop or-mid --target 1.5R --write            # по entry.json
python3 "${CLAUDE_SKILL_DIR}/exit.py" plan --symbol SBER --entry 325 --stop atr:1.5 --target resistance --write
python3 "${CLAUDE_SKILL_DIR}/exit.py" plan --symbol LKOH --stop swing --target 2R --mode swing --max-hold-days 10 --write
```
По тренду, без цели, с подтягиваемым стопом:
```bash
python3 "${CLAUDE_SKILL_DIR}/exit.py" plan --symbol SBER --stop atr:2 --target none --trail 3 --mode position --write
python3 "${CLAUDE_SKILL_DIR}/exit.py" update        # каждый вечер: подтянуть стоп (только в сторону прибыли)
```
Стопы: `or-mid`, `or-low`, `atr[:K]`, `swing`, `level:X`, `pct:X`. Цели: `1R`, `2R`…, `resistance`, `level:X`, `pct:X`. Результат — `trader/plan.json`. Цены округляются к шагу цены инструмента.

## Как выбирать

- Стоп должен стоять там, где идея сделки сломана, а не там, где «не жалко». Для пробоя — середина или край диапазона; для отката — за последним свингом; иначе 1,5–2 ATR.
- Стоп уже 0,5 ATR выбьет шум. Стоп шире 3 ATR раздувает риск и уменьшает размер позиции.
- Цель меньше 1,5R или ближе 4 издержек сделки бессмысленна при комиссиях (moex-risk такую заблокирует).
- Если на пути к цели сильное сопротивление, предложите цель чуть ниже него или частичную фиксацию.
- Внутри дня позиция закрывается до `flat_by` (по умолчанию 18:30 МСК) в любом случае: перенос через ночь — это гэп-риск, которого в плане нет.
- После плана — moex-timemachine.

## Общие правила

- Скрипты лежат в `${CLAUDE_SKILL_DIR}`, общая библиотека — в `${CLAUDE_SKILL_DIR}/../moex-setup/lib`. Состояние пишется в папку `trader/` текущего проекта (или `$TRADER_DIR`).
- Время везде — московское (МСК). `--now "YYYY-MM-DD HH:MM"` разбирает ситуацию на момент в прошлом.
- Бесплатные данные ISS Мосбиржи идут с задержкой около 15 минут. В реальном времени — через токен Т-Инвестиций (настраивается в moex-setup).
- Если скрипт пишет, что нет доступа к iss.moex.com или API Т-Инвестиций, значит у среды нет выхода в интернет к этим сайтам. Если подключён компьютер пользователя (есть инструмент для команд на его компьютере), запустите команду там. Иначе предложите выгрузить свечи в CSV (терминал брокера, экспорт Финама) и передать файл через `--file`. Не придумывайте цифры.
- Это инструмент, а не финансовая рекомендация. Не обещайте прибыль. Большинство людей, торгующих внутри дня, теряют деньги; комиссии — одна из главных причин.
