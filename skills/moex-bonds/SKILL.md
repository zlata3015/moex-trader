# moex-bonds — облигации

```bash
python3 "${CLAUDE_SKILL_DIR}/bonds.py" screen --kind ofz --max-years 3
python3 "${CLAUDE_SKILL_DIR}/bonds.py" screen --kind corp --min-spread 200 --min-turnover 3000000
python3 "${CLAUDE_SKILL_DIR}/bonds.py" show SU26248RMFS3
python3 "${CLAUDE_SKILL_DIR}/bonds.py" ladder --sum 30000 --rungs 3
```

## Как читать

- `screen` исключает валютные, структурные, конвертируемые, бессрочные выпуски и линкеры. Флоатеры показываются с `--floaters`. Выпуски с премией к ОФЗ выше 1000 б.п. скрыты: такая доходность обычно означает, что рынок закладывает дефолт (`--risky` покажет их).
- `show` считает поток сам и сверяет доходность с ISS. Большое расхождение значит, что данные нужно проверить вручную.
- Налог упрощён: купоны за вычетом уплаченного НКД и положительная разница с номиналом. Зачёт убытков не учтён.
- Чувствительность — первое приближение по дюрации. При большом движении ставки цена изменится иначе.
- Сравнение с фондом верно только при неизменной ставке. Если ставка снижается, доход фонда падает, а фиксированный купон остаётся.

## Правила

- Рейтинга в ISS нет. Без подтверждённого рейтинга корпоративный выпуск не рекомендуется.
- На одного корпоративного эмитента не больше 5% портфеля. Низкий рейтинг только по отдельному решению Маргариты.
- Премия к ОФЗ должна оправдывать риск. Высокая доходность без рейтинга — признак риска, а не выгоды.
- Выпуск только для квалифицированных инвесторов пропускается.
- Формат рекомендации — в инструкции проекта. Это расчёт, а не инвестиционная рекомендация.
